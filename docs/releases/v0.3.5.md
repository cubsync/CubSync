<summary><h3>中文说明</h3></summary>

一个小版本，两件事。

#### 修好了

**手机端现在把本机地址留在屏幕上。** 上一版点「启动服务端并等待远端连接」成功之后，端口只在一条四秒就消失的提示里出现过，屏幕上什么都没留下——而另一台机器要填的正是这个地址。现在服务端起来之后，那一张卡会换成「端口 43817」加上每张网卡的 `IP:端口`，点一下就复制。桌面端的「服务端（主控）」卡一直是这样显示的，手机端补上了同样的东西。

#### 发布说明改成可折叠

Release 页面是给人拿文件的，说明却排在下载项上面；说明一长，下载就要滑很久。现在：

- **语言块默认收起**（中文 / English）——不想读的那一半直接跳过；
- **语言里的各节默认展开**——选了语言就是选了要读，不必再点一轮；
- 标题按原文的层级渲染（`##` 是 `h3`，`###` 是 `h4`），不是一律加粗，所以大纲还在。

`tools/collapse-release-notes.py` 是把它做出来的脚本，对已经折叠过的文件重复运行是安全的。

#### 顺带

- 每一个旧版本的说明（v0.3.0 起）都按同一形状重排了一次。

<summary><h3>English</h3></summary>

A small release, two things.

#### Fixed

**The phone keeps its own address on screen.** Starting the server used to report itself
with a notice that disappeared after four seconds, leaving nothing behind — and that port
is exactly what the other machine has to type. The card now becomes 端口 43817 followed by
each interface's `IP:port`, tappable to copy. The desktop's 服务端（主控）card has always
shown this; the phone has it now too.

#### Collapsible release notes

A release page exists to hand somebody a file and the notes sit above the downloads, so a
long release makes every download a scroll. Now:

- the **language** block starts closed (中文 / English), so half of it can be skipped;
- the **sections** inside start open, because choosing a language is choosing to read it;
- headings keep the depth the file had (`##` renders as `h3`, `###` as `h4`) rather than
  being flattened to bold, so the outline survives.

`tools/collapse-release-notes.py` is the script that applies the shape, and re-running it
on an already-collapsed file does nothing.

#### Also

- Every older release's notes, back to v0.3.0, were reshaped the same way.
