#### 这一版改了什么

**深色模式能看清了。** 上一版把桌面深色换成了手机的颜色表，结果窗口底色和卡片底色是同一个值 —— 整窗一块黑板，卡片只剩一圈细线，说明文字糊在上面。现在回到设计稿里桌面自己的深色：画布 `#0F1116`、卡片 `#181B21`，中间的层次重新分得开；两档次要文字也提亮了，卡片里的整句说明不再需要凑近看。

**USB-ADB 不再是"已留位"。** 插上数据线，在「连接方式」里就能看到设备并发起连接：电脑端用 `adb forward` 把设备端口映射到本机，之后走的是和局域网完全一样的连接。手机端那一行现在是纯展示 —— 转发在电脑上做，手机只需要保持共享开启。

**协议协商**：没连上远端时，「远端版本」显示 `—`，不再显示 `0`（那个 0 读起来像协议之前的构建）。

#### 注意

- 两端请保持同一协议版本（v1）。旧版连新版会按 v3 兼容规则降级到单向。
- 桌面深色/浅色可在设置里切换；这一版只动了深色。
- Android 需要「所有文件访问」权限才能传输，首次打开会提示。

#### What changed

**Dark mode is readable again.** The previous version gave the desktop the phone's colour table, where the window background and the card background are the same value — one flat black field, cards held apart only by a hairline, and every explanatory line smeared into it. Dark now uses the design's own desktop tokens: canvas `#0F1116`, cards `#181B21`, with the layer between them visible again. The two secondary text weights were raised as well, so a sentence inside a card no longer needs to be leaned into.

**USB-ADB is no longer "reserved".** Plug in a cable and the device appears under 连接方式 and can be connected: the desktop runs `adb forward` to map the device's port onto this machine, and what follows is the same connection the local network uses. On the phone that row is a view rather than a switch — forwarding happens on the host, and the phone only has to keep sharing on.

**Protocol negotiation**: with no peer, the remote version reads `—` instead of `0`, which looked like a build from before the protocol existed.

#### Notes

- Keep both ends on the same protocol version (v1). An older peer falls back to one-way by the v3 compatibility rules.
- Dark and light are switchable in Settings; only dark changed here.
- Android needs all-files access to transfer; the first launch asks for it.
