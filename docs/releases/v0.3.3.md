<summary><h3>中文说明</h3></summary>

这一版把界面按原型（`素材/ui-prototype/cubsync-ui-demo.html`）逐值重做了一遍，并让**连接**与**传输**真正可用。

#### 这一版改了什么

**外观照原型取色。** 上一版把强调色换成了品牌靛蓝，还在代码注释里把它写成"有意的差异"——原型桌面端写的是 `--win-accent:#1e88e5`，手机端写的是 `--m3-primary:#4c6ef5`，两端本来就是两套色板。现在两套都照抄，圆角、字号也照抄（桌面卡片 12px、按钮 8px；手机卡片 20px、全宽按钮 999px 胶囊、底栏 64px）。

**桌面端有了自己的标题栏。** 原型画了一条 `.win-title`（标志 + CubSync + 设备芯片 + 三个窗控），照做之后就不再有 Windows 原生那条白色标题栏——它不跟随主题，之前深色窗口顶上永远是一条白。

**桌面端补上侧栏分组与底部状态栏。** 侧栏按原型分成「工作区 / 任务 / 其他」三组，下面是收藏夹与折叠按钮；窗口底部是一条 28px 状态栏（连接状态 / 速率 / 作业进度 / 版本）。

**「连接」页改名「连接设备」，并按原型重排。** 连接方式 + 协议协商并排，传输通道在下面。协议协商里的能力位、本地/对端协议版本、比对到的能力位数都是握手真实协商出来的，不是写死的。

**电脑端不再有「运行模式」。** 普通 / Root / Shizuku-ADB 是 Android 的能力，桌面端没有 root 这个概念——上一版把它放在电脑上是错的，已移除。

**手机端不再占用状态栏。** 改用系统状态栏 + 内容避让（状态栏与导航栏 insets），标题不会再和时钟叠在一起。

**手机端左滑可以拉出抽屉。** 之前只有左上角那个按钮能开。

**手机端设置补齐外观一节。** 主题三档、**动态取色（Material You）**（Android 12+ 真的从壁纸取主色）、靛蓝 / 紫 / 青 / 绿 / 橙 五个色相。

**缓冲块数默认值对齐原型**（1MB × 256，之前上限 16，连原型自己的默认值都输不进去）。

**所有图标改成矢量。** `☰ ⋮ ★ ☆` 这类字符在缺字形的字体下会画成方块——手机底栏整排消失、桌面侧栏变方块都是这个原因。现在全部是 `ImageVector`，路径取自原型。

#### 连接与传输

- 两端都能扫到本机真实网卡并按地址连上对端，握手协商结果（协议版本、能力位）在「连接设备」页可见。
- 桌面的「服务端（主控）」卡可以选共享目录、启动、把地址复制到另一台机器。
- 传输页两栏可以真实浏览本机与远端目录、进入子目录、选中条目并传送。
- 原型里画了、这一版还没打通的能力（USB-ADB、多链路、Shizuku / ADB）**照原型画出来并且可以点**，点了会说明当前走的是局域网。

#### 已知还差的

- 设备发现只有"手动填地址 + 之前连过"，没有局域网广播发现。
- 桌面「日志」页的过滤框、桌面「设置」页的保存按钮还没接（原型画了，这一版没做，没有留成假控件）。
- 手机端仍有若干说明性文字是上一版加的，正在按原型逐条清理。

<summary><h3>English</h3></summary>

This release redraws both interfaces value by value from the prototype
(`素材/ui-prototype/cubsync-ui-demo.html`), and makes **连接** and **传输** actually work.

#### What changed

**Colours come from the prototype.** The previous release substituted the brand indigo
for the accent and recorded the substitution in a comment as a deliberate difference. The
prototype gives the desktop `--win-accent:#1e88e5` and the phone `--m3-primary:#4c6ef5` —
two palettes on purpose. Both are copied now, along with the radii and the type scale
(desktop cards 12px, buttons 8px; phone cards 20px, full-width buttons as 999px pills, tab
bar 64px).

**The desktop draws its own title bar.** The prototype draws `.win-title` — mark, product
name, device chip, three window controls — and doing the same removes the native Windows
title bar, which does not follow the theme and was the white strip above a dark window.

**The desktop rail gains its three group labels and the window a status bar.** The rail
splits into 工作区 / 任务 / 其他 with the bookmark list and a fold button under it; a 28px
status bar carries connection state, rate, job progress and the version.

**连接 becomes 连接设备, laid out as drawn.** 连接方式 beside 协议协商, 传输通道 under both.
The capability chips, the local and peer protocol versions and the agreed-bit count are
what the handshake actually produced, not constants.

**The desktop no longer offers 运行模式.** 普通 / Root / Shizuku-ADB are Android
capabilities; a desktop has no root process, and offering the choice there was wrong.

**The phone stops covering the status bar.** System bars are transparent and the content
keeps clear of them, so the clock no longer lands on the title.

**The phone drawer opens with a left swipe**, not only from the menu mark.

**The phone's 设置 gains the appearance section**: three theme modes, **动态取色
(Material You)** — real wallpaper colour extraction on Android 12 and up — and the five
hue chips.

**缓冲块数 defaults to the prototype's 1MB × 256**; the previous ceiling of 16 made the
prototype's own default impossible to enter.

**Every icon is a vector.** `☰ ⋮ ★ ☆` render as boxes in a font without the glyph, which
is how the phone's tab bar shipped empty and the desktop rail filled with squares.

#### Connecting and transferring

- Both ends list this machine's real interfaces and dial a peer by address; the negotiated
  protocol version and capability bits are visible on 连接设备.
- The desktop's 服务端（主控）card picks shared folders, starts the server and copies the
  address to type on the other machine.
- The two panes browse local and remote folders for real, descend, select and transfer.
- Capabilities the prototype draws and this build has not wired — USB-ADB, multi-link,
  Shizuku / ADB — are drawn and are tappable, and say that traffic still goes over the LAN.

#### Still missing

- Device discovery is manual address plus remembered peers; there is no LAN broadcast.
- The desktop log filter and the desktop settings save button are not wired (the prototype
  draws them; this release leaves them out rather than shipping controls that do nothing).
- Some explanatory strings on the phone were added by the previous release and are being
  removed against the prototype.
