<summary><h3>中文说明</h3></summary>

这一版补上**所有文件访问**权限：上一版只让应用"看得见"，没让它"写得进去"。

#### 修好了

**安卓端不能传输文件——因为缺的不是一个权限，是另一个。** 上一版我补的是 `READ_MEDIA_*`（按类型读取），它解决的是"打开文件夹只有文件夹没有文件"。但同步工具要做的事超出它：

- 往**任意路径**写文件，而不只是媒体库认得的那几种；
- 读自己建的 `.cubtmp` 这类临时文件；
- 进 `Android/data` 下的目录。

这些只有 **`MANAGE_EXTERNAL_STORAGE`（所有文件访问）** 能覆盖。少了它，应用能看不能写——**一个传不了文件的传输工具**。

现在：Manifest 里声明，界面上检查，缺了就把你送到系统那个"允许访问所有文件"的设置页。这一项不能被弹窗授予，只能在那里打开，所以每次进入界面都会检查一次。

#### 上一版为什么没修好

**是我的流程错误，不是代码没写对**：权限修复合进主线是在 `v0.3.6` 打标签**之后**的，而你装的 APK 是从那个标签构建的 —— 包里根本没有修复。**修完就该出新版本号。**

#### 你这一版要验的

1. 进入应用，**弹不弹**权限请求 / 有没有把"所有文件访问"打开；
2. 打开一个文件夹，**能不能看到文件**；
3. **两端真的互传一个文件**。

前两条我在本机验不了（没有设备），第三条只能你走。

<summary><h3>English</h3></summary>

This release adds **all files access** — the previous one let the application see, not write.

#### Fixed

**Android could not transfer files, because the missing permission was the other one.** The
previous release added `READ_MEDIA_*`, which fixes a folder that listed its subfolders and
none of its files. A sync tool needs more than that: to write to **any** path rather than
the handful the media library knows, to read the `.cubtmp` files it creates itself, and to
go into directories under `Android/data`. Only **`MANAGE_EXTERNAL_STORAGE`** covers those,
and without it the app could look and not touch — a transfer tool that cannot transfer.

It is declared in the manifest, checked on the way in, and the application takes you to the
system page that grants it. That permission cannot be given from a dialog, so the check
happens every time.

#### Why the previous release did not fix this

A process mistake rather than a coding one: the permission change was merged after `v0.3.6`
was tagged, and the build came from that tag, so the APK did not contain it.
