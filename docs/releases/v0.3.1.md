<details>
<summary><h3>中文说明</h3></summary>

CubSync 0.3.1 把两端界面做到和设计稿一致：字段、档位、说法逐项对齐，两端的文件是同一份。

<details open>
<summary><h4>下载（同一个版本，任取其一）</h4></summary>

- `CubSync-0.3.1.msi` — Windows 安装包
- `CubSync-v0.3.1-windows-x64.zip` — Windows 绿色包，解压即用
- `CubSync-v0.3.1-debug.apk` — 安卓，侧载安装

</details>

<details open>
<summary><h4>这一版变好了什么</h4></summary>

- **传输页**：显示方式、行密度、列数、分栏方向、条目缩放都能调；每栏有自己的排序与作用范围；栏头就是地址，点空白即可改。
- **同步页**：先预览差异再运行；配置详情独立成层。
- **作业**：点开任一条，能看到结果、十三项明细、已传输与已跳过的文件级列表，以及那一次运行的日志。
- **设置**：九项浏览与传输偏好加外观，和设计稿一致。
- **连接**：运行模式、传输通道、账户状态、最近传输，一屏看完。
- 安卓图标改成白底、标志缩小，和其它应用一个重量。

</details>

<details open>
<summary><h4>注意</h4></summary>

- 安卓是 **debug 包**，未签名，仅供试用。
- 协议**未加密、未鉴权**：只在可信局域网里共享，不要开公网端口。
- USB-ADB 与多链路仍是如实的占位档位：协议支持多链路，界面先标出来。

</details>

<details>
<summary><h3>English</h3></summary>

CubSync 0.3.1 brings both interfaces up to the design document: the same fields, the same
step counts, the same words, written once.

<details open>
<summary><h4>Downloads (same version, take any)</h4></summary>

- `CubSync-0.3.1.msi` — installs on Windows
- `CubSync-v0.3.1-windows-x64.zip` — Windows, unpack and run
- `CubSync-v0.3.1-debug.apk` — Android, sideload

</details>

<details open>
<summary><h4>What is better in this one</h4></summary>

- **Transfer**: display mode, row density, column count, pane direction and item scale are
  all adjustable; each pane has its own sort and scope; the header *is* the address, and
  tapping the blank part of it edits it.
- **Sync**: preview the differences before running; a configuration opens as its own layer.
- **Jobs**: open any run and see its result, thirteen detail rows, the file-level lists of
  what was transferred and skipped, and that run's own log.
- **Settings**: the nine browsing and transfer preferences plus the appearance, as designed.
- **Connect**: run mode, channels, account state and recent transfers in one screen.
- The Android icon is white-grounded with a smaller mark, so it weighs the same as its
  neighbours on a home screen.

</details>

<details open>
<summary><h4>Notes</h4></summary>

- The Android build is a **debug** APK, unsigned, for trying out.
- The protocol is **unencrypted and unauthenticated**. Share on a trusted network only.
- USB-ADB and multi-link are honest placeholders: the protocol supports multiple links, the
  interface says so, and transfers still go over the local network.

</details>
