# CubSync 0.3.13

## 下载

- **Windows**：`CubSync-0.3.13.msi`（安装）或 `cubsync-0.3.13-windows.zip`（解压即用）
- **Android**：`cubsync-0.3.13-android.apk`

## 这一版修好的

**桌面**

- 打开「显示方式」或右键菜单时，两栏的文件不再消失。此前弹层占掉了整个内容区，看起来像文件被清空了。
- 「显示方式」弹层贴在按钮下方，不再飘到屏幕中间；五个档位都有图标。
- 通知条不再把整屏顶上去、在底部留一块空白。
- 点击任一栏即可切换焦点，被聚焦的一栏有明显的底色与边框；「显示方式」作用在聚焦的那一栏。
- 收藏夹按 **本端 / 远端**（以及远端协议）自动归类；点击在**当前聚焦**的那一栏打开，不再一律塞进左栏。
- 收藏夹可以删除；`+` 改成按地址添加任意目录，不再只能收藏当前这一栏。
- 「USB」连接真的能用了：列出 adb 设备，用 `adb forward` 把设备端口映射到本机后按普通连接协商。之前这个按钮只会弹一句「已留位」。
- 地址与端口分成两个输入框，端口留空就用对面显示的端口；不用再记住 `HOST:PORT` 的写法。
- 取色：第一个色块是标志的靛蓝，两端都叫「默认」，五个色块都带名称；「回到品牌靛蓝」按钮已删——它设的是第三种颜色。

**手机**

- 返回键按「关面板 → 回上一屏 → 回传输 → 上一层目录」的顺序退，只有真的没得退时才退出应用。
- 点「停止共享」后界面立刻恢复成「启动服务端」，不再停在旧状态。
- 面包屑显示**所有层**，每一层都能点；宽度不够时左右滑动，不再折叠成省略号，打开时自动停在当前目录那一端。
- 分栏方向按屏幕真实尺寸判断：横屏时「自动」会变成左右两栏。
- 副行的显示方式按钮改成长条「显示方式 · 详细」，与原型一致。
- 没有 Root 时，← 到 `/storage/emulated/0` 就停住，不再一路退到不可读的 `/`。
- 连接页直接有「连接另一台设备」：地址与端口两个输入框，不用再翻 ⋮ 菜单。
- 连上之后远端栏会打开对面共享的第一个目录；没连接时远端栏显示「还没有连接远端」，不再把本机磁盘当成远端。
- 在远端栏输入对面机器的绝对路径时，如果该路径不在对面共享范围内，会直接列出对面共享了哪些目录，而不是报「读不了这个文件夹」。
- 「本机」统一改称「本端」——远端可以是另一台电脑、另一块硬盘，或者以后的 WebDAV / FTP。「账户」一栏按协议列出每一端。

## 仍然没有的

- **Root / Shizuku** 两种运行模式还只是记录设置：它们需要一个走 `su` 或 Shizuku 的独立后端，本版没有。选了会如实说明，不会假装生效。
- **WebDAV / FTP / SFTP / SMB** 这些远端协议尚未实现；收藏夹的归类已经按协议留好位置。

# CubSync 0.3.13

## Downloads

- **Windows**: `CubSync-0.3.13.msi`, or `cubsync-0.3.13-windows.zip` to run without installing
- **Android**: `cubsync-0.3.13-android.apk`

## Fixed

**Desktop**

- Opening 显示方式 or a context menu no longer empties both panes — the overlay used to take the
  whole content area, so the files looked deleted.
- The 显示方式 card hangs under its button instead of floating in the middle of the window, and all
  five modes have their marks.
- A notice no longer pushes the screen up and leaves a blank band at the bottom.
- Clicking a pane switches focus, the focused pane is visibly tinted and outlined, and 显示方式
  applies to it.
- Favourites are grouped by 本端 / 远端 (and by remote protocol), and open in the **focused** pane
  instead of always on the left.
- Favourites can be deleted; `+` adds any folder by address rather than only the current view.
- USB works: it lists adb devices, forwards the device's port to this machine, then connects as
  usual. The button used to say 已留位.
- Address and port are two fields; leave the port empty to use the one the other side shows.
- 取色: the first chip is the mark's indigo, both ends call it 默认, every chip has its name, and
  the 回到品牌靛蓝 button — which set a third colour — is gone.

**Android**

- Back closes a panel, then a screen, then returns to 传输, then goes up one folder, and only exits
  when there is nothing left.
- 停止共享 updates the screen immediately.
- Breadcrumbs show every layer, each one tappable, scrolling sideways when narrow instead of
  folding into an ellipsis, parked at the current folder.
- 分栏方向 uses the real screen size, so 自动 turns into two columns in landscape.
- The display-mode pill reads 显示方式 · 详细, as the prototype draws it.
- Without root, ← stops at /storage/emulated/0 instead of climbing to an unreadable /.
- The connect screen has 连接另一台设备 with address and port fields, not just a hidden menu.
- After connecting, the remote pane opens on the first folder the other side shares; with no peer it
  says 还没有连接远端 instead of showing this phone's own disk.
- Typing the other machine's absolute path lists what it actually shares rather than 读不了这个文件夹.
- 本机 is now 本端 throughout: the far end may be another computer, another disk, or a WebDAV / FTP
  mount later. 账户 lists each end with its protocol.

## Still missing

- **Root / Shizuku** run modes only record a setting: both need a backend that speaks through `su`
  or Shizuku, and this build has none. Selecting them says so rather than pretending.
- **WebDAV / FTP / SFTP / SMB** are not implemented; favourite grouping already has a place for them.
