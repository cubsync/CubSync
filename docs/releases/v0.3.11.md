<summary><h3>中文说明</h3></summary>

这一版补上桌面上两处原型画了、实现没做的地方。

**日志页的过滤框。** 原型在「日志」标题右边有一个 `过滤…` 输入框。此前这一页只能按级别和区域筛，
按内容找一条记录只能靠眼睛——一个跑过几次同步的人，日志里几百行。现在那个框是真的：输入即过滤，
匹配内容或区域，和级别、区域两个筛选一起生效。

**同步页的「导出 .cubcfg」。** 原型在配置那条信息旁边放了这个按钮。导出本来就有（在左侧配置列表里），
现在也在原型的那个位置。

顺手把日志页里那句「日志视图尚不支持过滤」的注释删了——它已经不成立了。

#### 你这一版要验的

1. 日志页输几个字，行数是不是跟着变；
2. 同步页右上角的「导出 .cubcfg」能不能存出文件。

<summary><h3>English</h3></summary>

Two things the prototype draws on the desktop that the build had not drawn.

**The log page's filter box.** The prototype puts a `过滤…` box beside the 日志 heading.
The page could filter by level and by area, but finding one line by its content meant
reading; a few syncs put hundreds of lines in there. The box is real now: typing filters
on the message or the area, together with the two existing filters.

**导出 .cubcfg on the sync heading.** The prototype puts it beside the configuration chip.
Exporting already existed behind the configuration list; it is now also where the design
puts it.

The comment in the log page claiming the view had no filter is gone — it was no longer
true.

#### Worth checking in this build

1. Type in the log filter: does the line count follow?
2. Does 导出 .cubcfg on the sync heading write a file?
