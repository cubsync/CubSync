<summary><h3>中文说明</h3></summary>

两个看得见的排版问题。

**日志的时间列不再折行。** 之前那一列塞的是 `10-17 13:25:33`，宽 72dp 放不下，每条日志的时间都断成
两行，整页跟着高低不齐。现在两端都只印时刻（`13:25:33`），单行——原型里也是这么印的。

**同步页的「策略」不再把同一句话印两遍。** 面板标题旁的摘要和面板底下那行原本是同一句
（「双向同步；删除会同步，被删掉的文件进回收站；冲突时停下来等人决定。」）。现在只留上面那处。

<summary><h3>English</h3></summary>

Two layout defects that were visible.

**The log's time column no longer wraps.** It held `10-17 13:25:33` in 72dp, so every line's
time broke in two and the page came out uneven. Both ends now print the clock alone
(`13:25:33`), one line — which is what the prototype prints.

**同步's 策略 panel no longer prints the same sentence twice.** The summary beside the
panel title and the line under it were the same text (双向同步；删除会同步…；冲突时停下来
等人决定。). Only the first one stays.
