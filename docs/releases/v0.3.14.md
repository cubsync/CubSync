<summary><h3>中文说明</h3></summary>

#### 下载

- **Windows**：`CubSync-0.3.14.msi`（安装）或 `cubsync-0.3.14-windows-x64.zip`（解压即用）
- **Android**：`cubsync-0.3.14.apk`

#### 这一版修好的

**两端**

- 深色配色统一按手机端：桌面原来自己一套近黑（`#0F1116`），现在两端同值（`#141318`）。
- 按钮回到原型的样子：有边框、有底色、悬停有变化。以前很多「按钮」只是一行字（新建文件夹、
  右上三点菜单、手机设置里的默认显示模式），现在都是按钮。
- 开关 46×26、分段控件同高，不再一个大一个小地摆在一起。
- 浮窗提示跟随深浅色，且 **4 秒自动消失**，不用再点。
- 双栏焦点：点哪一栏哪一栏亮，显示方式作用在亮的这一栏。
- 栏头右上收紧间隔，并在收藏左边加了 **展开** 按钮：列出这一栏打开过的路径，一点直达。
- 连接之后，传输页的远端栏会列出**对面共享的全部文件夹**（以前只打开第一个）。

**收藏夹**

- 按 **本端 / 远端 · 协议** 自动归类，也可以新建自己的分组；收藏项可编辑名称与分组。
- 两端都有菜单：桌面右键、手机长按。菜单含 打开 / 编辑 / 上移 / 下移 / 取消收藏 / 新建分组 /
  添加路径 / 收藏夹设置（「添加账户」留了位置，远端协议尚未实现）。
- 顺序可调：桌面点右上「排序」后可**拖动**，手机菜单里上移/下移；
  原来的加号换成了排序图标，添加路径移到菜单里。
- 收藏之后左侧立刻出现，不用切页面。

**电脑端**

- 右键菜单出现在**鼠标位置**，不再一律显示在窗口中间。
- 选择文件夹…仍是系统对话框：可输入地址栏、随系统深色的自绘窗口还没做（见下）。

**手机端**

- 返回键回到**上一个功能**，不是一律回传输；再没有上一屏时才退出应用。
- 面包屑按 Mix 的方式工作：保留你打开过的最长路径，回到上层时下面几层仍在，
  **当前层高亮**，点任意一层直达；**长按任一层复制该层路径**。
- 连上之后连接卡显示对端名字、共享目录数与「断开」，按钮不再一直写着「连接」。
- 显示方式按钮只剩图标 + 档位名（去掉了多余文字）；没有列数的档位**不再显示列数行**，
  也没有「详细没有列数参数」这句废话。

#### 仍然没有的

- **Root / Shizuku 运行模式**：依旧是只记录设置。它们需要一个走 `su` / Shizuku API 的后端，
  这一版没有做——设备上的权限路径没有真机验证，宁可先不做，也不放一个看起来能用、实际读不了
  文件的东西进去。
- **远端协议（WebDAV / FTP / SFTP / SMB）**：收藏夹与账户的归类已按协议留位，协议本身未实现。
- **手机端收藏夹拖动排序**：用菜单里的上移/下移，桌面端可拖。
- **自绘的选文件夹窗口**：仍是系统对话框，因此不支持深色与地址栏。

<summary><h3>English</h3></summary>

#### Downloads

- **Windows**: `CubSync-0.3.14.msi`, or `cubsync-0.3.14-windows-x64.zip` to run without installing
- **Android**: `cubsync-0.3.14.apk`

#### Fixed

**Both ends**

- One dark palette, the phone's: the desktop had a near-black of its own (`#0F1116`); both are
  `#141318` now.
- Buttons look like the prototype again: a border, a fill, a hover. Several "buttons" were just a
  line of text — 新建文件夹, the ⋮ menu, the display-mode choices in the phone's settings.
- The switch is 46×26 and the segmented control matches it, instead of one being twice the other.
- Notices follow the theme and disappear after four seconds.
- The focused pane is the lit one, and 显示方式 acts on it.
- The pane header's three icons are tighter, and a new 展开 button beside the star lists the paths
  that pane has visited.
- After connecting, the remote pane lists **every** shared folder, not just the first.

**Favourites**

- Grouped by 本端 / 远端 and protocol, with custom groups; a row can be renamed and re-grouped.
- A menu on both ends — right click on the desktop, long press on the phone: open, edit, move up,
  move down, remove, new group, add path, favourite settings (添加账户 has a place reserved).
- Order is adjustable: drag on the desktop in 排序 mode, move up/down on the phone. The plus became
  a sort icon, and adding a path moved into the menu.
- A new favourite appears in the rail immediately.

**Desktop**

- The context menu opens at the pointer instead of the middle of the window.
- The folder picker is still the system dialog: a self-drawn one with an address bar and the app's
  dark theme is not in this build (see below).

**Phone**

- Back returns to the previous section instead of always 传输, and only exits at the top.
- Breadcrumbs keep the longest path you opened: going up leaves the deeper layers on screen, the
  current one lit and every layer tappable; a long press copies that layer's path.
- The connect card shows the peer's name, how many folders it shares and 断开.
- The display-mode pill is the mark and the mode only, and 列数 is hidden for modes that have no
  columns.

#### Still missing

- **Root / Shizuku**: still a recorded setting only. Both need a backend that speaks through `su`
  or the Shizuku API, and that path has not been verified on a device — a control that looks like it
  works and cannot read a file is worse than an honest gap.
- **WebDAV / FTP / SFTP / SMB**: the grouping has a place for them; the protocols are not built.
- **Dragging favourites on the phone**: use move up/down; the desktop supports drag.
- **A self-drawn folder picker**: the system dialog is still used, so no address bar and no dark theme.
