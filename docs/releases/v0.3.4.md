<summary><b>中文</b></summary>

这一版修的是 0.3.3 里"看着像 demo、用起来不像"的部分：图标与命中区统一、桌面端的显示方式回到弹出菜单、手机端回到长按、窗口能拖动，以及**两端真的能连上并传文件**。

<details open>
<summary><h3>能用了 / 修好了</h3></summary>

**手机端能启动服务端了。** 上一版点「启动服务端并等待远端连接」必然失败：服务端要求至少有一个共享目录，而手机端一个都没有，报的还是英文
`choose at least one folder to share`。现在首次运行就把本机可用存储根播种为共享目录，抽屉的「根」与 `⋮` 里的共享目录表可以改它。

**两端传输页打开就是真目录。** 上一版两个栏位打开在空路径上，看着就是"这个文件夹是空的"。现在本机栏打开在共享根/可用根上，连上对端后远端栏自动打开在对端暴露的目录上。

**电脑端窗口拖动不再消失。** 上一版按拖动位移改窗口坐标，而位移是在窗口内部量的——窗口一动，指针的局部坐标跟着动，形成反馈把窗口推走。现在按指针的**屏幕**坐标算，没有回路。

**电脑端不再突然空出一大块。** 传输页原来在 `.chead` 之外又加了一条自造副行（显示方式 / 新建文件夹 / 同步… / 收藏当前目录 / 送至对侧 / 取回本栏），与标题栏右侧的三个按钮重复，展开条还常驻在下面。原型桌面传输页没有副行，显示方式是标题栏上的**弹出菜单**——所以副行删了、常驻展开条删了、方向条回到原型的两枚箭头。

**显示方式按原型显示图标。** 桌面端弹出菜单里五个档名前面各有一枚对应图标；手机端展开条的五个档位就是五枚图标（原型 `.a-viewbar` 是图标不是文字）。图标是路径不是字符——原型用的 `⋮≡ ☰ ▤ ▦ ⇄` 在缺字形的字体上会画成方块。

**手机端传输页的按钮统一了。** 副行原来混着 34 与 38，且 `☰ ▤ ◧ ◨ ⋮ ▲ ▼` 全是字符；现在全是 38dp 命中区 + 路径图标。

**手机端中栏方向条删了。** 那是桌面的东西（原型 `.midbar` 只在桌面）。

**手机端行改为长按出动作面板。** 原来每行都挂一个 `⋮`，原型手机的行没有这个按钮；按原型：点击＝进目录/勾选，长按＝动作面板（传送 / 收藏 / 过滤 / 重命名 / 详情 / 删除），有选中项时底部出操作条（已选 N 项 · 传送 ▸ 远端 · ✕）。

**手机端抽屉不再盖住状态栏。** 内容按系统状态栏与导航栏让位。

**手机端「连接」页少了一节。** 「账户与连接状态」是自造的，原型只有 运行模式 / 传输通道 / 两个按钮 / 最近，已并进「最近」。

**图标按类型区分。** 文件夹 / 图片 / 视频 / 文档 / 普通文件各自一枚，两端一致。

**左上角标志的颜色对了。** 之前用界面令牌（`accent` / `info`）画标志，改配色就把小圆的青色改掉了。现在读品牌常量 `#3A5CCC` / `#1FA8A0`。

</details>

<summary><h3>变轻了</h3></summary>

- 桌面端不再依赖 `compose.components.resources`（没有任何代码路径用它）。
- 运行时镜像由 jlink 按 jdeps 结果裁剪，并显式声明 `modules("java.instrument", "jdk.unsupported")` + `includeAllModules = false`，防止将来某个依赖把整个 JDK 带回来。

</details>

- 桌面「日志」的过滤框、桌面「设置」的保存按钮仍没接（原型画了，不接就不画）。
- 自造文案仍在逐条清理中。

<summary><b>English</b></summary>

This release fixes the parts of 0.3.3 that looked like the prototype without behaving like
it: icons and hit areas made uniform, the desktop display control back in a drop-down, the
phone back on long-press, a window that stays where you put it — and **both ends actually
connecting and transferring**.

<details open>
<summary><h3>Working now</h3></summary>

**The phone can start its server.** The previous release could not: the server requires at
least one shared folder, the phone had none, and the error it returned was the English
`choose at least one folder to share`. The first run now seeds the phone's own shared
storage as a root, and 抽屉 → 根 plus the `⋮` sheet are where that is changed.

**Both transfer screens open on real folders.** They used to open on an empty path, which
is why both panes read 这个文件夹是空的. The local pane opens on a shared or usable root,
and the remote pane opens on the peer's roots the moment a handshake succeeds.

**The desktop window no longer vanishes when moved.** The drag applied the pointer's delta
measured inside the window, so moving the window moved the pointer's local coordinates by
the same amount — a feedback loop that walked the window off screen. It now uses the
pointer's *screen* position.

**The desktop no longer grows a dead band.** The transfer screen carried an extra sub-row
of its own (display mode, new folder, sync, favourite, send, fetch) duplicating the heading
buttons, plus a standing display bar. The prototype has neither: the display control is a
drop-down on the heading. Both are gone and the direction strip is the prototype's two
arrows again.

**Icons where the prototype draws icons.** The desktop drop-down puts a mark before each of
the five mode names; the phone's view bar is five marks rather than five words. The marks
are paths — the prototype's `⋮≡ ☰ ▤ ▦ ⇄` render as boxes in a font without them.

**The phone's transfer buttons are one size.** The sub-row mixed 34 and 38 and spelled its
controls `☰ ▤ ◧ ◨ ⋮ ▲ ▼` in characters; every one of them is now a 38dp target with a path.

**The phone's middle strip is gone** — that is a desktop control (`.midbar` is only drawn
there).

**Phone rows are long-press again.** Every row carried a `⋮`, which the prototype's phone
rows do not: a tap enters or ticks, a long press opens the action panel, and a selection
raises the bar along the bottom (已选 N 项 · 传送 ▸ 远端 · ✕).

**The drawer keeps clear of the system bars**, and the connect screen is down to the
prototype's four blocks — the 账户与连接状态 card was an addition and is folded into 最近.

**Rows are marked by what they are** — folder, image, video, document or plain file, the
same on both ends.

**The mark's colours are its own again.** Drawing it with the interface tokens meant the
palette change turned its small circle from teal to blue; it reads `#3A5CCC` / `#1FA8A0`.

</details>

<summary><h3>Lighter</h3></summary>

- The desktop dependency on `compose.components.resources` is gone — nothing on any code
  path used it.
- The runtime image is jlink-built from what jdeps finds, with
  `modules("java.instrument", "jdk.unsupported")` and `includeAllModules = false` stated so
  that a future dependency cannot quietly put the whole JDK back.
