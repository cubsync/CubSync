<summary><b>中文说明</b></summary>

CubSync 0.3.0 是第一个有界面的版本：桌面和安卓都能用。

**下载**（同一个版本，任取其一）
- `CubSync-0.3.0.msi` — Windows 安装包
- `CubSync-v0.3.0-windows-x64.zip` — Windows 绿色包，解压即用
- `CubSync-v0.3.0-debug.apk` — 安卓，侧载安装

**能做什么**
- **传输** —— 两边各一个文件夹栏，选好要送过去的东西，按中间那支箭头。
- **同步** —— 建立文件夹对和策略，先试运行看差异；断点续传；镜像删除进回收站，不是直接销毁。
- **作业与日志** —— 每次运行做了什么、跳过了什么、为什么失败。
- **两端同构** —— 桌面六个入口，手机五个（日志并入作业），说法一致。
- 局域网直连，不需要账号，不经过任何服务器。

**修掉**
- 安卓启动图标显示成一块蓝，看不到标志。
- 安卓上保存配置会崩溃，写入也可能失败。
- 双向同步的删除行为与界面上的说法相反。

**注意**
- 安卓是 **debug 包**，未签名，仅供试用。
- 协议**未加密、未鉴权**：只在可信局域网里共享，不要开公网端口。

<details>
<summary><b>English</b></summary>

CubSync 0.3.0 is the first release with an interface: desktop and Android.

**Downloads** (same version, take any)
- `CubSync-0.3.0.msi` — installs on Windows
- `CubSync-v0.3.0-windows-x64.zip` — Windows, unpack and run
- `CubSync-v0.3.0-debug.apk` — Android, sideload

**What it does**
- **Transfer** — a folder pane on each side. Select what to send, press the arrow between them.
- **Sync** — folder pairs and a policy, a dry run to see the differences first, resume,
  and mirrored deletions that go to a trash folder instead of being destroyed.
- **Jobs and logs** — what each run did, what it skipped, and why something failed.
- **The same on both ends** — six entries on the desktop, five on the phone, the log
  folded into the job it came from. The same words in both.
- Direct over the local network. No account, nothing in between.

**Fixed**
- The Android launcher icon showed a block of colour instead of the mark.
- Android: saving a configuration crashed, and writing a file could fail.
- Two-way sync described its deletion behaviour backwards.

**Notes**
- The Android build is a **debug** APK, unsigned, for trying out.
- The protocol is **unencrypted and unauthenticated**. Share on a trusted network only —
  do not expose the port to the internet.
