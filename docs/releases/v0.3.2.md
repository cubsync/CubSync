<summary><b>中文说明</b></summary>

CubSync 0.3.2 把手机端做到和设计稿同一个结构，并让两端的功能图标不再依赖字体。

**下载**（同一个版本，任取其一）
- `CubSync-0.3.2.msi` — Windows 安装包
- `CubSync-v0.3.2-windows-x64.zip` — Windows 绿色包，解压即用
- `CubSync-v0.3.2-debug.apk` — 安卓，侧载安装

**这一版变好了什么**
- **图标**：两端的导航、返回、星标、刷新、抽屉等全部换成矢量图形。之前用的是 `☰`、`⋮`、`★` 这类字符，碰上没有这些字形的字体就渲染成方块——移动端的底部导航就这样整排消失过。
- **手机 · 连接**：运行模式收成一张可折叠的卡（卡头直接写当前档，默认收起）；传输通道改成按网卡多选，列出的是这台机器真实的网卡和地址；下面就是「启动服务端并等待远端连接」和「浏览文件（双栏）」；再往下是账户与连接状态、最近传输。填地址连接与共享目录放进右上角的 ⋮。
- **手机 · 同步**：配置列表带选中高亮；配置详情里方向、比较、冲突、删除各是一行「选一个」，文件夹对可就地改；「比较并预览差异」直接进预览。
- **手机 · 差异预览**：顶部一排气囊（对数 / 冲突 / 新增 / 更新 / 删除），下面按文件夹对分组，最后是「执行同步」。
- **手机 · 正在同步**：大字百分比、按文件夹对逐条进度与状态、断点续传说明、暂停与取消并保留续传信息。
- **手机 · 作业**：作业与日志两段在同一页，右侧显示进行中数量；点任一条进独立详情屏。
- **手机 · 设置**：外观在前（主题 / 当前生效 / 强调色），浏览与传输九项在后，和设计稿同序。
- **抽屉**：用产品自己的标志做头图。
- 提示条 4 秒后自动消失，不再一直挡着内容。

**注意**
- 安卓是 **debug 包**，未签名，仅供试用。
- 协议**未加密、未鉴权**：只在可信局域网里共享，不要开公网端口。
- USB-ADB 与多链路仍是如实的占位档位：协议支持多链路，界面先标出来，传输本身仍走局域网。

<summary><b>English</b></summary>

CubSync 0.3.2 brings the phone up to the same structure as the design, and stops both
interfaces depending on a font for their icons.

**Downloads** (same version, take any)
- `CubSync-0.3.2.msi` — installs on Windows
- `CubSync-v0.3.2-windows-x64.zip` — Windows, unpack and run
- `CubSync-v0.3.2-debug.apk` — Android, sideload

**What is better in this one**
- **Icons**: navigation, back, star, refresh and the drawer are all vector shapes now.
  They used to be characters — `☰`, `⋮`, `★` — and a font without one of those glyphs drew
  a box. That is how the phone's whole bottom bar once disappeared.
- **Phone · Connect**: the run mode folds into a card whose heading says which mode is
  active; the channels are per-card switches over this machine's real interfaces and
  addresses; then the one button that starts sharing, then the accounts, then what was
  transferred recently. Dialling an address and choosing shared folders live behind `⋮`.
- **Phone · Sync**: the list marks the selected configuration; the configuration's
  direction, comparison, conflict and delete rules are each a row that opens a list; the
  folder pairs edit in place; "compare and preview" goes straight to the diff.
- **Phone · Differences**: a row of counts across the top, one group per folder pair, and
  the button that runs it.
- **Phone · Running**: a large percentage, per-pair progress and state, the resume note,
  and pause / cancel-and-keep-resume-information.
- **Phone · Jobs**: jobs and the log are two halves of one screen, with the number in
  flight on the right; any entry opens its own detail screen.
- **Phone · Settings**: appearance first (theme, what is in effect, accent), then the nine
  browsing and transfer preferences, in the design's order.
- **Drawer**: the product's own mark heads it.
- A notice leaves on its own after four seconds instead of sitting over the content.

**Notes**
- The Android build is a **debug** APK, unsigned, for trying out.
- The protocol is **unencrypted and unauthenticated**. Share on a trusted network only.
- USB-ADB and multi-link are honest placeholders: the protocol supports multiple links, the
  interface says so, and transfers still go over the local network.
